# MLops
- 실행 기준: docker compose run --rm pipeline
## 프로젝트 개요
본 프로젝트는 배치 기반 추천 시스템을 위한 MLOps 환경을 구축하는 것을 목표로 한다.  
데이터 수집 → 전처리 → 모델 학습 → 평가 → 배치 추론 → API 서빙까지의 전 과정을 자동화하며,  
Airflow와 Docker를 활용해 재현 가능하고 운영 가능한 추천 파이프라인을 구현한다.

---

## 전체 아키텍처 개요
- 배치 기반 추천 시스템 구조
- 학습 및 추론 파이프라인은 Airflow로 스케줄링
- 모든 파이프라인은 Docker 컨테이너로 실행
- 모델 및 결과 아티팩트는 공용 저장소(S3 등)에 저장
- FastAPI를 통해 추천 결과 제공

---

## 프로젝트 구조
- src/
- data/ # 데이터 로딩 및 전처리
- train/ # 모델 학습 및 평가
- batch/ # 배치 추론 및 추천 결과 생성
- api/ # FastAPI 기반 추천 결과 서빙
- db/ # DB 연결 및 쿼리
- dags/ # Airflow DAG 정의
- docker/ # Dockerfile 및 컨테이너 설정
- configs/ # 환경 및 파이프라인 설정 파일

## 협업 및 프로젝트 관리 방식
- GitHub Issues를 기반으로 작업 단위 관리
- GitHub Projects(Board)를 활용한 작업 상태 관리
